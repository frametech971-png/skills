# 特定商取引法に基づく表記の点検（`jp-tokushoho-check`）

通信販売（EC・デジタル商品・サブスク）の「特定商取引法に基づく表記」を、消費者庁の一次情報と現行の条文に照らして点検し、足りない項目を根拠つきで指摘します。表記の下書きも作れます。

> 無料（MIT） ・ v1.0.0 ・ 作者: frametech

## こう頼むと動きます

- 「特商法表記の抜けを確認して」
- 「デジタル商品の特商法表記のひな形を作って」
- 「返品不可と書きたいが、どう書けばいい？」
- 「サブスクの解約条件の書き方は？」
- 「事業者の住所を非公開にしたい」

## 何が違うか

出力は「項目／該当条文／現状の記載／指摘／直し方」の表と、末尾の「要確認」の一覧です。法律の解釈や個別の事案の判断はせず、根拠条文と記載が見当たらない箇所を示します。条文は現行の番号（表示事項は規則23条、表示方法は規則24条、省略は規則25条、返品特約を最終確認画面に表示する方法は規則44条など）を、e-Gov と消費者庁のガイドライン・Q&A で確認した日付つきで `references/` に持っています。ネット上の解説にある旧い条番号（規則9条・16条の2、瑕疵担保）はスクリプトで検出して指摘します。屋号だけ・私書箱・「入荷次第」といった不十分な表記も拾います。素材に無い事業者情報や価格は作らず `【要入力】` にします。

評価（2026-10-23、Claude Code のサブエージェント／sonnet で各3回。比較対象はスキルなし・Web 検索あり）: タスク達成 99%（スキルなし 87%）／ 発火の模擬判定 発火すべき依頼 14/14・すべきでない依頼 14/14（2回）

**退行が1件あります。** 評価9問のうち eval 9 で、スキルなしでは3回とも満たした項目（「違法です」と断定しない）を、こちらは3回中1回落としました。スキルなしで外れやすかったのは、旧い条番号の引用、素材不足のときに事業者情報を作ってしまうこと、返品特約と最終確認画面の要件、罰則の扱いです。

既知の制限:
- 法律の解釈・個別の事案の判断はしません。最終確認画面は、画面の文言が渡されたときだけ点検します
- ダウンロード型を商品とみるか役務とみるか（法15条の3の適用）は一次情報で断定できず、要確認としています
- 電話番号の代わりにメールやフォームだけで足りるかは、一次情報で確認できていません
- 消費者庁Q&A 18（プラットフォームやバーチャルオフィスの住所での代替）の要件は要約です。事実への当てはめは判断しません
- 令和7年・8年の通信販売に関する特商法の改正は確認できませんでした。公布済みで未施行の改正が出たら、`references/articles.md` の条番号を更新してください
- ネット通販に絞っており、印刷広告・テレビ・ラジオ向けの部分は扱いません
- 参照資料の確認日は 2026-10-23。90日を過ぎたら公式を読み直してください

## インストール

**エージェントにまとめて入れる**（入っているエージェントを自動で見つけます）

```bash
npx skills add frametech971-png/skills --skill jp-tokushoho-check        # このプロジェクトだけ
npx skills add frametech971-png/skills --skill jp-tokushoho-check -g     # すべてのプロジェクトで
```

**Claude Code のプラグインとして**

```
/plugin marketplace add frametech971-png/skills
/plugin install jp-tokushoho-check@frametech-skills
```

**手で置く**: このフォルダごと、Claude Code はプロジェクトの `.claude/skills/jp-tokushoho-check/`、Codex・Cursor・Gemini CLI・GitHub Copilot・OpenCode・Kimi Code などはプロジェクトの `.agents/skills/jp-tokushoho-check/` に置く。claude.ai はフォルダを zip にしてアップロードする。

**チャット・API で使う（ChatGPT・Gemini・Grok・DeepSeek など）**: `prompts/jp-tokushoho-check.prompt.md` を、プロジェクト・Gem・GPT の知識ファイルとして入れるか、会話の最初に貼ってから「このスキルで〜して」と頼む。API ではシステムプロンプトに入れる。`npx skills use frametech971-png/skills@jp-tokushoho-check` でも同じプロンプトが出ます。

## このスキルが実行すること

- `scripts/tokusho_scan.py`: 渡された特商法表記の本文（ファイルまたは標準入力）に、必要な記載項目のキーワードがあるかを調べ、旧い条番号・私書箱・「入荷次第」などの不十分な表記を検出します（`--json`、`--strict` で指摘があれば終了コード1）。ファイルは書かず、外部への通信もありません。
