## 法（通信販売の節）

| 条 | 内容（要約） |
|---|---|
| 2条 | 通信販売の定義 |
| 11条 | 広告の表示事項。1号 販売価格（送料が別なら送料も）、2号 代金の支払の時期と方法、3号 引渡時期・提供時期、4号 申込みの期間に関する定めがあるときはその旨と内容、5号 申込みの撤回又は解除に関する事項（15条の3第1項ただし書の特約があればその内容を含む）、6号 そのほか主務省令（規則23条）で定める事項。**ただし書**: 広告に、請求により事項を記載した書面を遅滞なく交付し、又は電磁的記録を遅滞なく提供する旨を表示するときは、省令で定めるところにより一部を表示しないことができる |
| 12条 | 誇大広告等の禁止。著しく事実に相違する表示、実際より著しく優良・有利と誤認させる表示（撤回・解除に関する事項を含む） |
| 12条の3〜12条の5 | 承諾をしていない者への電子メール広告・ファクシミリ広告の提供禁止等。**メール配信の同意は本スキルの対象外** |
| 12条の6 | 特定申込み（書面の申込み、インターネットの申込み画面）を受けるとき、その書面・画面に、1項1号 商品・役務の分量、2号 11条1〜5号の事項 を表示する義務。2項 申込みとなることについて誤認させる表示、1項の事項について誤認させる表示の禁止 |
| 13条の2 | 申込みの撤回・解除を妨げるための不実の告知の禁止 |
| 14条 | 主務大臣の指示。1項2号 顧客の意に反して申込みをさせようとする行為（規則42条1項: 申込み内容を、申込みとなる操作の際に容易に確認・訂正できるようにしていないこと） |
| 15条の3 | 通信販売における契約の解除等。商品・特定権利は引渡し・移転を受けた日から8日を経過するまで申込みの撤回・解除ができる。ただし、広告に撤回等についての特約を表示していた場合（電子消費者契約などは、広告に加えて省令で定める方法でも表示）は特約による。引取り・返還の費用は購入者の負担 |
| 15条の4 | 特定申込みの意思表示の取消し。12条の6の不実表示・不表示・誤認させる表示で誤認し申込みをしたときは取り消せる |
| 26条 | 適用除外。2027-07-22 施行予定の改正（金融商品取引法・資金決済法の一部改正）で文言が変わる予定。通販の表示事項（11条・12条の6・15条の3）の文言は、確認した2026-10-23時点の予定版でも変わらない |

## 規則（通信販売の節）

| 条 | 内容（要約） |
|---|---|
| 23条 | 法11条6号の事項。1号 氏名又は名称、住所、電話番号。2号 法人でインターネットなど電子情報処理組織で広告するときは、代表者又は通信販売業務の責任者の氏名。3号 外国法人・外国に住所を有する個人で国内に事務所等があるときはその所在場所と電話番号。4号 販売価格・送料以外の負担金の内容と額。5号 引き渡された商品が種類又は品質に関して契約の内容に適合しない場合の販売業者の責任についての定めがあるときはその内容。6号 プログラム記録物の販売、映画・音楽等を鑑賞させる役務、プログラムをファイルに記録させる役務のときは、利用に必要な電子計算機の仕様・性能その他の条件。7号 2回以上継続して契約する必要があるときは、その旨と金額、契約期間その他の販売条件。8号 販売数量の制限その他の特別の販売条件。9号 一部省略して書面・電磁的記録の請求に費用がかかるときはその額。10号 通信販売電子メール広告をするときは事業者のメールアドレス |
| 24条 | 表示方法。1号 送料は金額で。2号 引渡時期・提供時期は期間又は期限で。3号 撤回・解除に関する事項（返品特約を含む）は、顧客にとって見やすい箇所で明瞭に判読できるように、その他容易に認識できるように |
| 25条 | 11条ただし書による省略の範囲。負担金を全部表示しない場合と全部表示する場合で省略できる事項が違う。**返品の可否・条件・費用負担、23条6〜10号の事項は省略できない。** 契約不適合責任を負わない旨などの例外あり（原文の但し書を読む）。3項 インターネットでは、事項を電磁的方法で提供する旨の表示でも一部を表示しないことができる（技術的基準は4項） |
| 26条 | 12条の対象となる事項（性能・内容・関与・原産地、11条各号の事項） |
| 42条 | 14条1項2号の行為（申込み内容の確認・訂正）、メール広告の承諾の取り方 |
| 44条 | 15条の3第1項ただし書の方法。申込みとなる操作を行うための表示（最終確認画面）で、見やすい箇所に明瞭に判読できるように、容易に認識できるように表示 |

## 現行と食い違いやすい点（C21 で検出）

| 古い記載 | 現行 | 補足 |
|---|---|---|
| 規則第9条、第16条の2（返品特約の表示方法） | 規則第24条第3号、第44条 | 古い解説・会員向け資料に残っている。検索結果の要約にも現れる |
| 瑕疵担保責任 | 契約の内容に適合しない場合の責任（契約不適合） | 民法改正に合わせた用語。規則23条5号 |
| 「返品不可」だけ | 品質に問題のない商品の返品可否と、契約不適合の責任を区別して書く | 通達 |
| 「特商法11条に基づく表記」だけで足りる | 最終確認画面にも法12条の6の事項が要る | 広告で11条どおり書いても12条の6第1項の義務を果たしたことにならない（ガイドライン別添9） |
| 「通販にクーリング・オフがある」「ない」 | クーリング・オフは無い。引渡しから8日の撤回・解除（15条の3）はあり、広告で特約を表示すれば特約が優先 | 消費者庁Q&A |
| 「電話番号は不要」 | 原則は表示。省略は11条ただし書の要件を満たす場合のみ | `omission.md` |

## 改正の動き

- 令和3年改正（令和3年法律第72号）で、定期購入に関する12条の6、15条の4などが新設され、令和4年6月1日に施行された。出典: https://www.caa.go.jp/policies/policy/consumer_transaction/amendment/2021/
- 令和7年・令和8年の通信販売に関する特商法の改正は、消費者庁の改正一覧（https://www.caa.go.jp/policies/policy/consumer_transaction/amendment/）に載っていないことを確認した（2026-10-23）。e-Gov の改正履歴でも通販の表示事項の文言に変更は見つからなかった。公布済みで未施行の改正が出たら、このスキルの条番号の表を更新する
- 規則は令和8年5月21日施行の改正命令を含む。改正内容の詳細は確認していない（要確認）
