## 条文の要点（現行。令和8年6月14日時点の番号）

| 条 | 内容 | ポリシー点検での見どころ |
|---|---|---|
| 17条1項 | 利用目的をできる限り特定する | 「事業活動に用いるため」「マーケティング活動に用いるため」「お客様のサービスの向上」は特定したことにならない例。第三者提供を想定するなら、その旨が分かるように特定する |
| 17条2項・21条3項 | 利用目的の変更は、変更前と関連性を有すると合理的に認められる範囲まで。変更したら本人に通知か公表 | 「予告なく変更」だけの記載は足りるか要確認。変更時の通知・公表の方法を書く |
| 18条1項 | 特定した利用目的の達成に必要な範囲を超えて取り扱うには、あらかじめ本人の同意 | 目的外利用の同意の取り方 |
| 19条 | 違法・不当な行為を助長・誘発するおそれがある方法で利用しない | ポリシーに書く項目ではないが、プロファイリング等を書く場合に意識 |
| 20条1項・2項 | 偽りその他不正の手段で取得しない。要配慮個人情報はあらかじめ本人の同意なく取得しない（例外あり） | 病歴・信条・犯罪歴などを扱うなら取得方法と同意を書く |
| 21条1項 | 取得時、あらかじめ公表している場合を除き、速やかに利用目的を本人に通知か公表 | ポリシーを公表しておくのが基本の手当て |
| 21条2項 | 契約書、入力画面など直接書面（電磁的記録を含む）で本人から取得するときは、あらかじめ利用目的を明示 | 会員登録フォーム・問い合わせフォームの入力画面に目的を出す |
| 21条4項 | 通知・公表が不要な場合（取得の状況から利用目的が明らかな場合など） | 「明らか」と言えるかは個別判断。広く適用できると断定しない |
| 22条 | 正確性の確保、不要になったら遅滞なく消去する努力義務 | 保存期間・削除の記載があるか |
| 23条 | 安全管理措置（漏えい・滅失・毀損の防止） | 具体的措置の記載。ガイドライン別添（通則編 §10）に項目あり |
| 24条 | 従業者の監督 | 研修・秘密保持などを書く場合 |
| 25条 | 委託先の監督 | 委託の有無、委託する事務の内容を明らかにすることは重要（通則編の法40条の項の注記） |
| 26条1項・2項 | 漏えい等の個人情報保護委員会への報告と本人への通知。規則7条の事態（要配慮個人情報が含まれる、財産的被害のおそれ、不正の目的、本人が1,000人を超える）。規則8条: 速報は速やかに（目安として概ね3〜5日以内）、確報は30日以内（不正の目的のものは60日以内） | ポリシーへの記載は法定ではない。窓口・連絡手順を内部で用意しているかを聞く |
| 27条1項 | 個人データの第三者提供はあらかじめ本人の同意（例外は各号） | 提供先、提供する項目、目的 |
| 27条2項 | オプトアウト（本人の求めで提供を停止する、事項を本人に通知か容易に知り得る状態に置き、個人情報保護委員会に届出）。要配慮個人情報などは対象外 | 使うなら事項の公表が要る。届出の有無を要確認 |
| 27条5項1号 | 利用目的の達成に必要な範囲で取扱いを**委託**する場合の提供先は「第三者」に該当しない（委託された業務の範囲内でのみ） | 委託と第三者提供の書き分け。提供先が自社の目的で使うなら委託ではない可能性 |
| 27条5項2号 | 事業承継に伴う提供も第三者に該当しない | 合併・事業譲渡の記載 |
| 27条5項3号・6項 | **共同利用**: その旨、共同して利用する項目、共同利用者の範囲、利用目的、管理責任者の氏名または名称・住所・代表者名を、あらかじめ本人に通知か容易に知り得る状態に置く。責任者の変更は遅滞なく、利用目的・責任者の変更は事前に | 5事項が全部あるか |
| 28条1項〜3項 | 外国にある第三者への提供。原則、あらかじめ「外国にある第三者への提供を認める旨」の本人の同意。同意を得る際は規則17条の情報（外国の名称、その国の個人情報保護制度の情報、提供先の措置）を提供。提供先が相当措置を継続的に講ずる体制（規則16条）を整備している場合は28条1項の同意は不要だが、27条の規律（本人の同意、委託など）は別に必要で、28条3項の措置と本人の求めに応じた情報提供（規則18条）も要る | 外国のクラウド・SaaS・業務委託先。委託でも外国なら28条の整理が別に要る |
| 29条・30条 | 第三者提供の記録・確認義務 | ポリシーの記載事項ではない。別ガイドライン（第三者提供時の確認・記録義務編） |
| 31条1項 | **個人関連情報**（Cookie 等の端末識別子に紐づく閲覧履歴など）を提供する場合で、提供先が個人データとして取得することが想定されるときは、提供先で本人の同意が得られていることの確認が要る | Cookie・タグで外部に渡す場合の整理。ポリシーで同意取得の方法を説明するのが実務。提供先が個人データとして取得するかは事実関係次第なので要確認 |
| 32条1項 | **保有個人データ**について、本人の知り得る状態（本人の求めに応じて遅滞なく回答する場合を含む）に置く事項: (1)事業者の氏名または名称・住所・法人は代表者の氏名 (2)全ての保有個人データの利用目的（21条4項1〜3号の場合を除く） (3)32条2項の求め・33条1項・34条1項・35条1項3項5項の請求に応じる手続（38条2項で手数料を定めたときはその額）(4)令10条の事項: ①23条の安全管理のために講じた措置（支障を及ぼすおそれのあるものを除く）②保有個人データの取扱いに関する苦情の申出先 ③認定個人情報保護団体の対象事業者ならその名称と苦情解決の申出先 | **ポリシーの核**。この5〜6点が揃っているかを必ず見る。安全管理措置は「通則編に沿って実施」だけでは適切でないとされる。外国で保管するなら外的環境（その国の制度の把握）も措置の例に挙がる |
| 32条2項・3項 | 本人から求められたら保有個人データの利用目的を遅滞なく通知。通知しない決定をしたらその旨を通知 | 利用目的通知の求めの窓口 |
| 33条 | 開示請求。電磁的記録の提供など規則30条の方法で請求できる。開示しない場合の通知。第三者提供記録も開示の対象（33条5項） | 開示の方法（電子データ可）を書く |
| 34条・35条・36条 | 訂正等、利用停止・消去・第三者提供の停止の請求、理由の説明 | 請求できる内容を書く |
| 37条 | 請求の受付方法を定められる（令12条: 申出先、様式、本人確認の方法、手数料の徴収方法）。代理人（令13条: 法定代理人、委任による代理人）。本人に過重な負担を課さない | 窓口、書式、本人確認、代理人 |
| 38条 | 手数料（利用目的の通知・開示について定められる） | 手数料の有無と額。無料なら「無料」と書く |
| 40条 | 苦情の適切かつ迅速な処理に努める、体制整備に努める（努力義務）。ガイドラインはプライバシーポリシーの公表や委託処理の透明化も重要としている | 苦情窓口 |
| 41条〜46条 | 仮名加工情報・匿名加工情報の義務 | 作成・提供する場合だけ。別ガイドライン（仮名加工情報・匿名加工情報編）。ポリシーでの公表事項は要確認 |

## 現行と食い違いやすい点

- 引用された条番号が古い: 現行で23条は**安全管理措置**、25条は**委託先の監督**、27条が**第三者提供**、32条が**保有個人データの公表等**、33条が**開示**、40条が**苦情処理**。「第23条に基づき第三者提供」「第25条に基づき開示」と書いてあれば旧番号の可能性が高い。現行の番号に直すよう指摘する
- 「保有個人データ」は、令5条（令和8年6月14日時点）で除外されるのは存否が明らかになると本人・第三者の生命等に危害が及ぶ、違法・不当な行為を助長する、国の安全が害される、公共の安全と秩序の維持に支障が及ぶ、の4類型で、**「6か月以内に消去するもの」は入っていない**。旧来のひな形にある「6か月以内に消去する個人データは保有個人データに含めない」は現行に合わないので指摘する
- 規則7条の漏えい報告対象に「本人の数が1,000人を超える」が入っている（2026-10-21 時点のガイドライン引用）

## 未施行の改正（令和8年改正）

- 個人情報保護法等の一部を改正する法律は令和8年7月10日に成立、7月17日に公布。施行期日は「原則として公布の日から起算して2年を超えない範囲内」で、具体的な日付はこの確認では未取得（**要確認**）
- 概要資料（令和8年7月、個人情報保護委員会事務局）が挙げる主な内容: 統計情報等の作成にのみ利用する場合の同意不要（30条の2、31条の3）／16歳未満の者の同意・通知を法定代理人に（35条9項・10項、40条の2、58条の3）／顔特徴データ等の取扱いに関する周知の義務化とオプトアウトによる第三者提供の禁止（21条の2、27条2項、35条7項・8項）／委託を受けた事業者の義務の見直し（30条の3、58条の2）／漏えい時の本人通知の緩和（26条2項）／特定の個人への働きかけが可能な情報の不適正利用・不正取得の禁止（31条の2）／オプトアウトの提供先の身元・利用目的の確認（27条7項）／課徴金（148条の3以降）
- 上の条番号は**改正後の条番号**で、現行の条文ではない。施行前の事業者に適用された義務としては指摘せず、「施行予定の改正。顔特徴データや16歳未満の個人情報を扱うなら動向を要確認」と案内する
- 出典: https://www.ppc.go.jp/personalinfo/legal/r8kaiseihogohou/ （2026-10-21 確認）、概要 https://www.ppc.go.jp/files/pdf/260717_kaiseihounitsuite.pdf
- 政令・規則・ガイドラインの整備が進行中（同ページ）。最新は同ページで確認する
