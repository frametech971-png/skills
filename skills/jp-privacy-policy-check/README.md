# 日本のプライバシーポリシー点検（`jp-privacy-policy-check`）

Web サービス・アプリのプライバシーポリシーを、個人情報保護法と電気通信事業法の外部送信規律に照らして点検し、足りない項目を根拠条文つきで指摘します。ひな形（下書き）も作れます。

> 無料（MIT） ・ v1.0.0 ・ 作者: frametech

## こう頼むと動きます

- 「プライバシーポリシーの抜けを確認して」
- 「個人情報保護法に沿ったプライバシーポリシーのひな形を作って」
- 「Cookie や Google Analytics は何を書けばいい？」
- 「第三者提供と委託の書き分けを教えて」
- 「開示請求の窓口の書き方は？」

## 何が違うか

出力は「項目／該当条文／現状の記載／指摘／直し方」の表と、末尾の「要確認」の一覧です。法的な結論は断定せず、根拠条文と、記載が見当たらない箇所を示すところまでを役目にしています。条文は個人情報保護委員会のガイドラインに引用された現行の条番号（第三者提供は27条、安全管理は23条、開示は33条など）で、令和8年改正法のうち施行前の部分は現行の義務と分けて書きます。事業の実態（取得するデータ、目的、渡す先、使うツール）が素材に無いときは、事実を作らず聞き返すか「要確認」にします。ひな形の空欄は `【要入力】` で示します。

評価（2026-10-22、Claude Code のサブエージェント／sonnet で各3回。比較対象はスキルなし・Web 検索あり）: タスク達成 97%（スキルなし 79%）／ 発火の模擬判定 発火すべき依頼 11/11・すべきでない依頼 12/12（2回）
スキルなしで外れやすかったのは、素材が足りないときに住所や手数料を作ってしまうこと、委託と第三者提供の条文の結びつけ（25条・27条5項）、外部送信規律の対象判定の整理、日本の法律の範囲外（GDPR）の扱いです。

## 動作確認

Agent Skills 形式（`SKILL.md`）のスキルです。対応しているエージェント（Claude Code・Codex・Cursor・Gemini CLI・GitHub Copilot・OpenCode・Kimi Code ほか79種、2026-10-07 時点）ではフォルダのまま使えます。読み込みの仕組みが無いチャットや API では、貼り付け版（1ファイル）を使います。

| 使い方 | 実機で確認した環境・モデル | 確認日 |
|---|---|---|
| エージェントに入れる | Claude Code ／ sonnet（サブエージェント） | 2026-10-22 |
| チャット・API に貼る | 未確認 | — |

上の表にない環境は、Agent Skills 形式に準拠していますが未検証です。

必要なもの: 追加で必要なものはありません。`scripts/pp_scan.py`（Python 3.9 以上、標準ライブラリだけ）は、ポリシー本文に記載項目のキーワードがあるかを調べます。

既知の制限:
- 条文の確認日は 2026-10-21。90日を過ぎたら公式（e-Gov 法令検索、個人情報保護委員会、総務省）を読み直してください。作業時に e-Gov がメンテナンス中で、条文はガイドラインの引用で確認しています
- 令和8年改正法は未施行の部分が多く、施行日は未確認です
- 外部送信規律の対象になるかは事業の実態によるため、断定しません
- `pp_scan.py` はキーワードの有無を調べるだけで、記載が適切かは判断しません
- 個別の法的助言、GDPR など日本以外の法域、利用規約の作成は対象外です

## インストール

**エージェントにまとめて入れる**（入っているエージェントを自動で見つけます）

```bash
npx skills add frametech971-png/skills --skill jp-privacy-policy-check        # このプロジェクトだけ
npx skills add frametech971-png/skills --skill jp-privacy-policy-check -g     # すべてのプロジェクトで
```

**Claude Code のプラグインとして**

```
/plugin marketplace add frametech971-png/skills
/plugin install jp-privacy-policy-check@frametech-skills
```

**手で置く**: このフォルダごと、Claude Code はプロジェクトの `.claude/skills/jp-privacy-policy-check/`、Codex・Cursor・Gemini CLI・GitHub Copilot・OpenCode・Kimi Code などはプロジェクトの `.agents/skills/jp-privacy-policy-check/` に置く。claude.ai はフォルダを zip にしてアップロードする。

**チャット・API で使う（ChatGPT・Gemini・Grok・DeepSeek など）**: `prompts/jp-privacy-policy-check.prompt.md` を、プロジェクト・Gem・GPT の知識ファイルとして入れるか、会話の最初に貼ってから「このスキルで〜して」と頼む。API ではシステムプロンプトに入れる。`npx skills use frametech971-png/skills@jp-privacy-policy-check` でも同じプロンプトが出ます。

## このスキルが実行すること

- `scripts/pp_scan.py`: 渡されたプライバシーポリシーの本文（ファイルまたは標準入力）に、利用目的・第三者提供・開示請求の窓口などの記載項目のキーワードがあるかを調べて一覧にします。ファイルは書かず、外部への通信もありません。
