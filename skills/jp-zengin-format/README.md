# 全銀フォーマット（振込データ）の作成・検証（`jp-zengin-format`）

全国銀行協会の全銀フォーマット（総合振込・給与振込・賞与振込の振込データ、固定長120バイト）を CSV から作り、既存のファイルを検証します。半角カナの名義の変換もできます。

> 無料（MIT） ・ v1.0.0 ・ 作者: frametech

## こう頼むと動きます

- 「振込データを全銀フォーマットで作って」
- 「このファイルの桁数が合っているか検証して」
- 「半角カナへの変換（濁点・小文字）をして」
- 「トレーラの合計が合わない」
- 「給与振込と総合振込の違いは？」

## 何が違うか

ヘッダ・データ・トレーラ・エンドの4種のレコード、各項目の桁数と属性、使える文字、総合振込（21）・給与振込（11）・賞与振込（12）の種別を、全銀協の別冊（令和8年10月版）と、銀行2行の公開仕様で確認して `references/` に持っています。`generate` は桁や文字に問題があるとファイルを作らず一覧を出して止まり、`validate` はトレーラの件数・合計金額の差額まで表示します。銀行ごとに差がある部分は断定せず、取引銀行の仕様書での確認を促します。

評価（2026-10-23、Claude Code のサブエージェント／sonnet で各3回。比較対象はスキルなし・Web 検索とコード実行あり）: タスク達成 99%（スキルなし 84%）／ 発火の模擬判定 発火すべき依頼 12/12・すべきでない依頼 15/15（2回）

**退行が1件あります。** 評価9問のうち eval 2 で、スキルなしでは満たした項目（トレーラの合計がデータレコードの振込金額の合計であるという説明）を、こちらは3回中1回落としました。スキルなしで外れやすかったのは、半角カナの変換規則、レコードの桁、種別ごとの違い、銀行ごとの差です。

必要なもの: Python 3.9 以上（標準ライブラリだけ）。サンプルの CSV（架空の値）が `assets/` にあります。実行できない環境では、`references/` のレイアウト表で手作業の手順を示します。

既知の制限:
- 銀行の取り込み画面での成功は未検証です（公開仕様との突き合わせと自己検証まで）
- 文字コードは Shift_JIS 系（cp932）のみです。EBCDIC・全銀TCP/IP手順・ZEDI・口座振替(91)は対象外です
- 統一金融機関番号・統一店番号の一覧は持たず、口座の実在や振込指定日が営業日かは検証しません
- 銀行ごとの差は、全銀協・三菱UFJ信託銀行・群馬銀行の3資料で確認できた範囲だけです。ゆうちょ銀行と信用金庫の資料は本文を取得できず未確認です
- 長音「ｰ」と中黒「・」の扱いは全銀協の文字表で確認できず、断定せず確認を促します
- 参照資料の確認日は 2026-10-23。90日を過ぎたら公式を読み直してください

## インストール

**エージェントにまとめて入れる**（入っているエージェントを自動で見つけます）

```bash
npx skills add frametech971-png/skills --skill jp-zengin-format        # このプロジェクトだけ
npx skills add frametech971-png/skills --skill jp-zengin-format -g     # すべてのプロジェクトで
```

**Claude Code のプラグインとして**

```
/plugin marketplace add frametech971-png/skills
/plugin install jp-zengin-format@frametech-skills
```

**手で置く**: このフォルダごと、Claude Code はプロジェクトの `.claude/skills/jp-zengin-format/`、Codex・Cursor・Gemini CLI・GitHub Copilot・OpenCode・Kimi Code などはプロジェクトの `.agents/skills/jp-zengin-format/` に置く。claude.ai はフォルダを zip にしてアップロードする。

**チャット・API で使う（ChatGPT・Gemini・Grok・DeepSeek など）**: `prompts/jp-zengin-format.prompt.md` を、プロジェクト・Gem・GPT の知識ファイルとして入れるか、会話の最初に貼ってから「このスキルで〜して」と頼む。API ではシステムプロンプトに入れる。`npx skills use frametech971-png/skills@jp-zengin-format` でも同じプロンプトが出ます。

## このスキルが実行すること

- `scripts/zengin.py`: `generate`（CSV から120バイト固定長を生成。`--dry-run`、既存ファイルは `--force` なしでは上書きしません）、`validate`（桁・文字種・レコード順・トレーラの件数と合計金額を検査）、`kana`（半角カナ変換）。通信せず、ファイルは指定した出力先にだけ書きます。
- `scripts/selftest_zengin.py`: 実際に生成したファイルの桁とトレーラを別計算と照合する自己検査です（43項目）。
