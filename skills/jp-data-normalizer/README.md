# 日本語データの表記ゆれ直し（`jp-data-normalizer`）

名簿・顧客リスト・CSV の全角半角、電話番号、郵便番号、住所、和暦と西暦、文字コードの表記ゆれを、列ごとに安全に揃えます。元のファイルは書き換えず、別ファイルと変更の要約、「要確認」の一覧を返します。

> 無料（MIT） ・ v1.0.0 ・ 作者: frametech

## こう頼むと動きます

- 「この顧客リストの全角半角と電話番号の表記を揃えて」
- 「住所を都道府県・市区町村・番地に分けて」
- 「昭和63年を西暦に」
- 「令和8年3月は西暦で何年？」
- 「CSVが文字化けする（Shift_JIS と UTF-8）」
- 「郵便番号をハイフンつき7桁に」

## 何が違うか

住所の分割は辞書が無いと誤るので、確信が持てない行は直さずに「要確認」の列へ出します。和暦は明治〜令和の境界日と元年を扱い、電話番号は総務省の番号計画の市外局番の表で桁を判定します。Excel 向け CSV の BOM つき UTF-8 と CP932 の違い、半角カナの濁点の結合、長音・ダッシュの種類など、全角半角の落とし穴を `references/` にまとめています。直した出力をもう一度通しても変更が0行になる（冪等）ことを確認しています。

評価（2026-10-22、Claude Code のサブエージェント／sonnet で各3回。比較対象はスキルなし・Web 検索とコード実行あり）: タスク達成 100%（スキルなし 97%）／ 発火の模擬判定 発火すべき依頼 12/12・すべきでない依頼 12/12（2回）

**差は小さいスキルです。** 全角半角、和暦、郵便番号、文字コードの定番処理は、スキルなしでもコードを書いて実行できるため、ほぼ同じ結果になりました。このスキルの利点は、すぐ使える CSV 用のスクリプト（`--dry-run`、元ファイルを上書きしない、要確認の列）と、市外局番の表、和暦の境界の参照資料が手元に揃っていることです。貼り付け版は市外局番の表とスクリプトのため大きく（約2万トークン超の見込み）、`SKILL.md` に省略してよい部分を書いています。

上の表にない環境は、Agent Skills 形式に準拠していますが未検証です。

必要なもの: Python 3.9 以上（標準ライブラリだけ）。実行できない環境でも、本文の手順で判断できます。

既知の制限:
- 住所の分割は辞書なしです。確信が持てない行は要確認に出します
- 市外局番の候補が複数ある番号は、指定状況の表にある範囲で決めます。表に無い新しい市内局番は誤ることがあります
- 日付は時刻つき・2桁の年・Excel のシリアル値を読みません（要確認に出します）
- 漢数字の丁目は変換しません
- 明治の開始日（1868-01-25）は一次情報で確認できておらず、二次資料の換算表との一致です

## インストール

**エージェントにまとめて入れる**（入っているエージェントを自動で見つけます）

```bash
npx skills add frametech971-png/skills --skill jp-data-normalizer        # このプロジェクトだけ
npx skills add frametech971-png/skills --skill jp-data-normalizer -g     # すべてのプロジェクトで
```

**Claude Code のプラグインとして**

```
/plugin marketplace add frametech971-png/skills
/plugin install jp-data-normalizer@frametech-skills
```

**手で置く**: このフォルダごと、Claude Code はプロジェクトの `.claude/skills/jp-data-normalizer/`、Codex・Cursor・Gemini CLI・GitHub Copilot・OpenCode・Kimi Code などはプロジェクトの `.agents/skills/jp-data-normalizer/` に置く。claude.ai はフォルダを zip にしてアップロードする。

**チャット・API で使う（ChatGPT・Gemini・Grok・DeepSeek など）**: `prompts/jp-data-normalizer.prompt.md` を、プロジェクト・Gem・GPT の知識ファイルとして入れるか、会話の最初に貼ってから「このスキルで〜して」と頼む。API ではシステムプロンプトに入れる。`npx skills use frametech971-png/skills@jp-data-normalizer` でも同じプロンプトが出ます。

## このスキルが実行すること

- `scripts/normalize.py`: CSV を読み、`--map 列名=型` で指定した列を正規化して別ファイルに書き出します（既存のファイルは `--force` なしでは上書きせず、入力と同じパスは拒否します）。`--dry-run`、`--try 型 値`（1件の確認）、`--to-wareki`（西暦→和暦）つき。外部への通信はありません。
